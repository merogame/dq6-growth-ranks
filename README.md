# ドラクエ6 仲間の順位 ver1.00

[▶ ver1.00のページを開く](https://merogame.github.io/dq6-growth-ranks/)

スマホ版『ドラゴンクエストVI』の仲間16人について、**加入時点から同じ経験値を追加した場合**のレベル・平均能力値・順位を比較する非公式のWebページです。

## 使い方

1. 数値入力またはスライダーで、全員に追加する経験値を指定します。
2. 表の **Lv・HP・MP・ちから・すばやさ・みのまもり・かしこさ・かっこよさ** の見出しを押すと、その項目の高い順に並び替えます。
3. 「前の変化」「次の変化」で、選択中の項目の順位が変化する経験値へ移動できます。
4. 「加入時」で初期状態、「全員MAX」で全員が上限に達する経験値に切り替えます。

選択中の列は色と下向き矢印で表示します。同値は同順位（1位・1位・3位）です。スマホ幅では、力・早・守・賢・美の略記を使用します。比較条件とキャラクター別出典は右上の情報ボタンから確認できます。

## 比較条件

- 各キャラクターの加入時の累計経験値を出発点とし、そこに同じ量の経験値を加算します。
- 装備・職業補正・職業マスターの能力ボーナス・種や木の実・イベントによる追加強化を除外します。
- D-naviのスマホ版レベル別掲載値を平均値として使用しています。実際の成長には個体差があります。
- レベル間の数値は補間せず、到達済みレベルの掲載値を使います。
- 上限到達後は能力値を固定します（はぐりんはLv16、他の15人はLv99）。
- 加入時のレベル・累計経験値には各キャラクターの掲載表の最初の行を使用しています。

## データ出典

[ドラクエ6完全攻略D-navi](https://dq6.d-navi.net/chara) の各キャラクター「ステータス」ページ。取得日：2026年11月1日。

`data.js` の各キャラクターに参照URLを収録しています。各行は `[レベル, 累計経験値, HP, MP, ちから, すばやさ, みのまもり, かしこさ, かっこよさ]` の順です。

## ファイル構成

- `index.html`：画面と比較条件
- `style.css`：一画面で比較するためのレイアウト
- `app.js`：経験値計算・順位計算・見出しによる並べ替え
- `data.js`：16人のレベル別データと出典URL
- `VERSION`：バージョン番号
- `CHANGELOG.md`：更新履歴

ビルド・外部ライブラリー・APIキーは不要です。ダウンロード後、`index.html` をブラウザーで開くと利用できます。GitHub Pagesではリポジトリ直下をそのまま配信します。
